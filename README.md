# Ієрархія #include у С++

## Опис проєкту

Настільний застосунок для автоматичного аналізу та візуалізації залежностей між файлами С++ за директивами #include.

Програма зчитує файли проєкту, знаходить підключення інших файлів та будує їхню ієрархічну структуру.

## Можливості

- Відкриття С++ проєкту шляхом вибору папки або головного файлу.
- Читання файлів форматів .cpp, .h та .rc.
- Аналіз директив #include.
- Побудова ієрархії залежностей між файлами.
- Графічне відображення ієрархії.
